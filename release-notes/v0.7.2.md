# v0.7.2

Released 2026-11-16 20:03 UTC from `9863b40`. These are the bullets of that release's *What's new*, as published.

- **An exit node that sleeps no longer reports the same adverts over and over.** A batch of observations that went out and was never answered now keeps its identity across a deep sleep, so the server recognises it as the batch it already has instead of storing every advert a second time at each wake. A board that does not sleep is unaffected.
