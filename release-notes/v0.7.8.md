# v0.7.8

Released 2026-11-25 19:00 UTC from `a6243dd`. These are the bullets of that release's *What's new*, as published.

- **One result the server will not take no longer holds back every result behind it.** A result turned away for what it says is now dropped, counted and said — the console's `status` and `jobs` show it, with the http status — and the results behind it go out in the same breath. A result that simply did not reach the server is kept and sent again, as before.
- **A release now carries its notes as a file of its own.** `WHATSNEW.md` holds what is new in it, beside the images, so meshmaster.dk can show what an update brings on the page where it is offered instead of sending you to GitHub to read it.
- **Each board now appears on your network under a name of its own.** It calls itself `meshmaster-` and the last four characters of its hardware address, so two boards are two lines in the router's list of leases instead of one. `status` shows the name and the hardware address beside each other — reserve an address in the router by the latter.
