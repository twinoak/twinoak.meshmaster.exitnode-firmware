# v0.7.5

Released 2026-11-20 17:24 UTC from `ac412e7`. These are the bullets of that release's *What's new*, as published.

- **An exit node that has stopped hearing now puts its own receiver back.** On 19 November a board sent and was heard all night but got almost no replies until it was restarted. Its radio's receiver is now reset every four seconds, so a night like that should end by itself; `status` says the interval and `set agc.reset.interval <seconds>` changes it.
