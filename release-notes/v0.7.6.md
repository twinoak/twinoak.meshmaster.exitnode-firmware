# v0.7.6

Released 2026-11-21 14:11 UTC from `f7eae8f`. These are the bullets of that release's *What's new*, as published.

- **`status` now has the `stack` line it was supposed to have.** How much of the loop task's stack has never been used was only in `get mqtt.status`, so the line 0.7.4 announced was not where it said it was. Both commands show it now, and `get mqtt.status` keeps the observer's two broker tasks' lines beside it.
- **A board now closes its broker connections while it fetches an update, and a download that stumbles no longer gives up so soon.** A range that stopped short but brought bytes is carried on, only three empty answers in a row end a fetch, and the line that refuses one says why — the error and the memory the board had. The slots come back by themselves.
