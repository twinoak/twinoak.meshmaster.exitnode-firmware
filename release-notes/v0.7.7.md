# v0.7.7

Released 2026-11-22 20:33 UTC from `be69234`. These are the bullets of that release's *What's new*, as published.

- **A unit that sleeps between check-ins no longer stops at two jobs.** When it has finished what it was given and the server says more is waiting, it asks again — until the queue is empty or its airtime, its seconds or its battery say stop — so an evening's worth of reports and samples can go out in one wake instead of over five. A board that is always on is unchanged.
- **A job is no longer lost when the answer to a claim goes missing.** Every claim now tells the server which jobs this exit node already has in hand, so work it handed over but the board never heard of is given back — and a unit that sleeps asks again at once instead of waiting for its next check-in. Nothing is run twice.
- **Replies now come back the way the request went.** Before every login an exit node tells the repeater the route home, so answers return along the hops a trace measures instead of being flooded across the mesh, and a job's log says how each reply came. A pair that is good one way and poor the other can now fail where a flood sometimes got through.
